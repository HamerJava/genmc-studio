# YouTube upload package

Title: GenMC — Minecraft skins, built together with WebMCP

Description:
GenMC is a minimalist Minecraft skin studio for people and agents. A shared UV atlas maps every body part, face and overlay on the 64×64 canvas. Native WebMCP tools read the live state and apply precise, reversible edits using the same engine as the visible editor.

Try it: https://genmc-studio.kolio.chatgpt.site
Source (MIT): https://github.com/HamerJava/genmc-studio

Built with Codex, React, Vinext, Three.js, ChatGPT Sites, Cloudflare D1/R2 and native WebMCP.

This narrated walkthrough uses actual public app captures. Voice is synthetic. Future structures, texture packs and mods are a roadmap, not shipped features. The GenMC marker is a removable origin hint, not general AI detection and not Google SynthID. Independent project, not affiliated with Mojang or Microsoft.
